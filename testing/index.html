📱 How to Install on Android

  1. Tap the button above to download the .apk file.
  2. Once downloaded, open your device's "Files" or "Downloads" app.
  3. Tap on the app-debug.apk file.
  4. If prompted, allow installation from unknown sources (you may be redirected to Settings).
  5. Confirm the install when prompted.
  6. Once installed, tap "Open" to launch SeatSearchPro!
